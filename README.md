 🤖 AI Chatbot

A modern AI chatbot built using HTML, CSS, and JavaScript, powered by the Google Gemini API.

This project was created to learn and demonstrate frontend development, REST API integration, asynchronous JavaScript, Markdown rendering, and browser Local Storage.

✨ Features

- 🤖 AI-powered conversations using Gemini API
- 💬 User and AI chat messages
- 🌓 Dark and Light mode
- 🆕 New Chat functionality
- 💡 Prompt suggestion buttons
- ⏳ Thinking indicator while waiting for the AI response
- 💾 Local Storage for saving conversations
- 🔄 Chat messages remain available after page refresh
- 📜 Automatic scrolling for new messages
- 📝 Markdown support for AI responses
- **Bold text** support
- 📋 Lists and headings in AI responses
- ⚠️ API error handling
- 🖥️ Desktop-friendly chat interface

 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Gemini API
- Fetch API
- Local Storage
- Marked.js
- Font Awesome
